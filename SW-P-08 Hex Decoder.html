Command reference

Many routers implement only a subset of SW-P-08, and some vendors number a few commands differently. Codes below are merged from several sources; the tags show who documents each one. A dash in the layout column means only the name is known — the decoder then shows the raw bytes and any readable text.

Framing: DLE STX (10 02) · DATA (command + message) · BTC = length of DATA · CHK = 8-bit two’s complement of DATA + BTC · DLE ETX (10 03). Any 10 inside DATA, BTC or CHK is sent doubled (10 10). 10 06 = ACK, 10 15 = NAK. In standard commands, Matrix/Level packs matrix in bits 4–7 and level in bits 0–3; the multiplier carries Dest DIV 128 in bits 4–6, a bad-source flag in bit 3 and Src DIV 128 in bits 0–2. Extended commands (bit 7 set) send matrix and level as separate bytes and numbers as 16-bit DIV 256 / MOD 256 pairs.
